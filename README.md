# 🐍 Python 3 - Curso Completo (Luiz Otávio Miranda)

Este repositório reúne meus estudos, exercícios práticos, scripts de automação e projetos desenvolvidos ao longo do curso **Python 3 do Básico ao Avançado**, ministrado pelo professor **Luiz Otávio Miranda**.

O objetivo deste repositório é consolidar o domínio da linguagem Python, abordando desde a lógica de programação até conceitos avançados de Orientação a Objetos, estruturas de dados e boas práticas de código.

---

### 🧠 Conteúdos e Conceitos Mapeados

- 🔤 **Lógica de Programação & Sintaxe Fundamental:**
  - Tipos de dados (str, int, float, bool), variáveis e operadores.
  - Estruturas condicionais (`if`, `elif`, `else`) e estruturas de repetição (`while`, `for`).
  - F-strings, formatação de dados e fatiamento de strings.

- 📦 **Estruturas de Dados:**
  - Listas (`list`), Tuplas (`tuple`), Dicionários (`dict`) e Conjuntos (`set`).
  - List Comprehension e Dictionary Comprehension.
  - Empacotamento e desempacotamento de elementos.

- ⚙️ **Funções & Programação Funcional:**
  - Definindo funções (`def`), parâmetros padrão e `*args` / `**kwargs`.
  - Escopo de variáveis e funções de primeira classe.
  - Expressões Lambda, `map`, `filter` e `reduce`.
  - Decoradores (`@decorators`) e tratamento de exceções (`try`, `except`, `finally`).

- 🏗️ **Programação Orientada a Objetos (POO):**
  - Classes, atributos, métodos e métodos mágicos (`__init__`, `__str__`, etc.).
  - Encapsulamento, Herança, Polimorfismo e Classes Abstratas (`abc`).
  - Composição e Agregação de objetos.

- 🛠️ **Módulos & Manipulação de Arquivos:**
  - Leitura e escrita de arquivos (`open`, `json`).
  - Módulos padrão da linguagem e criação de pacotes próprios.
